# Apunts: Llenguatge de Marques i Sistemes de Gestió d'Informació (1r ASIX)

## 1. Origen del Web

La **World Wide Web (WWW)** va ser creada per **Tim Berners-Lee** el **1989-1991** al CERN (Suïssa), amb l'objectiu de compartir documents científics de manera fàcil entre investigadors.

**Elements que va crear per fer-ho possible:**

| Element | Funció |
|---|---|
| **HTML** | Llenguatge per estructurar els documents |
| **HTTP** | Protocol per transmetre'ls per la xarxa |
| **URL** | Sistema per identificar/localitzar cada document |

> Idea clau: el Web **no és el mateix que Internet**. Internet és la xarxa física global (existia des dels anys 60-70, amb ARPANET); el Web és un servei que funciona **sobre** Internet, basat en documents enllaçats entre si.

## 2. Què és l'hipertext

**Hipertext:** text que conté **enllaços (links)** a altres textos, permetent una lectura **no lineal** — pots saltar d'un document a un altre simplement clicant.

**Diferència amb el text tradicional:**

| Text tradicional | Hipertext |
|---|---|
| Es llegeix de forma lineal (d'inici a fi) | Es pot navegar saltant entre documents |
| Un sol document | Xarxa de documents interconnectats |
| Ex: un llibre en paper | Ex: una pàgina web amb enllaços |

> Idea clau: l'hipertext és el concepte **teòric** (idea d'informació connectada per enllaços); el Web és la **implementació pràctica** d'aquesta idea a escala mundial.

## 3. La World Wide Web (WWW)

Sistema d'informació distribuït que permet accedir a documents (pàgines web) **enllaçats entre si mitjançant hipertext**, a través d'Internet.

**Els tres pilars del funcionament del Web:**

```
URL (on és el document) 
    + 
HTTP (com el demano/transmeto) 
    + 
HTML (com està estructurat el document)
```

**Exemple pràctic:** quan escrius `https://www.exemple.com`, el navegador fa servir **HTTP** per demanar el document identificat per l'**URL**, i el resultat és un fitxer **HTML** que el navegador interpreta i mostra.

## 4. Què és un llenguatge de marques

**Llenguatge de marques (markup language):** sistema per **anotar/estructurar un text** mitjançant marques (etiquetes) que indiquen com s'ha d'interpretar o mostrar aquella part del contingut, **sense ser un llenguatge de programació** (no té lògica, bucles, variables...).

**Exemples de llenguatges de marques:**
- **HTML** (per pàgines web)
- **XML** (per estructurar/transportar dades)
- **Markdown** (el que estem fent servir ara mateix en aquests apunts!)

> Idea clau: un llenguatge de marques **separa el contingut de la seva estructura/presentació**. El text és la informació; les marques diuen "això és un títol", "això és una llista", etc.

## 5. Etiquetes (tags)

Les **etiquetes** són els símbols que defineixen la marca dins del document. En HTML, normalment van entre `< >` i solen tenir una etiqueta d'obertura i una de tancament.

**Estructura bàsica d'una etiqueta HTML:**

```html
<etiqueta>contingut</etiqueta>
```

**Exemples:**

| Etiqueta | Significat |
|---|---|
| `<p>...</p>` | Paràgraf |
| `<h1>...</h1>` | Títol principal |
| `<a href="...">...</a>` | Enllaç (hipertext!) |
| `<ul><li>...</li></ul>` | Llista |

**Exemple complet:**
```html
<h1>Els meus apunts</h1>
<p>Aquest és un <a href="https://exemple.com">enllaç</a> a una altra pàgina.</p>
```

> Idea clau: cada etiqueta té un **significat semàntic** (què és aquell contingut), no només visual — per això és important triar l'etiqueta correcta i no només la que "es veu bé".

---

**Idea clau general:** el Web va néixer per connectar documents mitjançant hipertext; per fer-ho possible calia un llenguatge de marques (HTML) que estructurés aquests documents amb etiquetes, un protocol (HTTP) per transmetre'ls, i un sistema d'adreces (URL) per localitzar-los — tres peces que, juntes, formen la World Wide Web.

Paraules clau: Llenguatge de marques, l'origen del Web, què és l'hipertext, la World Wide Web, que és un llenguatge de marques, etiquetes.
