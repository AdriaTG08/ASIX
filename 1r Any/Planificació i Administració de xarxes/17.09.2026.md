# Apunts: Fonaments i Arquitectura de Xarxes (1r ASIX)

## 1. Fonaments — Història

**ARPANET** (1969): primera xarxa de commutació de paquets, creada pel Departament de Defensa dels EUA. És l'origen d'Internet.

**ALOHANET** (1971, Hawaii): xarxa pionera que va introduir el mètode d'accés per contenció (base del futur Ethernet) per comunicar illes sense cablejat.

> Idea clau: ARPANET va demostrar que es podia enviar informació dividida en paquets per una xarxa distribuïda; ALOHANET va resoldre com compartir un mateix medi entre diversos dispositius.

## 2. Model OSI (7 capes)

| Capa | Nom | Funció | Exemple |
|---|---|---|---|
| 7 | Aplicació | Interfície amb l'usuari | HTTP, FTP, DNS |
| 6 | Presentació | Format, xifrat, compressió | SSL/TLS, JPEG |
| 5 | Sessió | Obre/tanca/gestiona sessions | NetBIOS, RPC |
| 4 | Transport | Comunicació extrem a extrem | **TCP, UDP** |
| 3 | Xarxa | Encaminament entre xarxes | **IP**, ICMP |
| 2 | Enllaç | Comunicació dins la mateixa xarxa | MAC, Ethernet, Switch |
| 1 | Física | Transmissió de bits (senyal elèctric/òptic) | Cables, Hub |

**Truc per recordar (de dalt a baix):** *"A Presidenta Sense Tacte No Enganya"* (Aplicació, Presentació, Sessió, Transport, Xarxa, Enllaç, Física).

## 3. IP, TCP i UDP

### IP (capa 3 — Xarxa)
S'encarrega d'**adreçar i encaminar** paquets entre xarxes diferents. Cada dispositiu té una adreça IP única (dins la seva xarxa).

### TCP vs UDP (capa 4 — Transport)

| | TCP | UDP |
|---|---|---|
| Connexió | Orientat a connexió (handshake) | Sense connexió |
| Fiabilitat | Garanteix arribada i ordre | No garanteix res |
| Velocitat | Més lent (té control d'errors) | Més ràpid |
| Ús típic | Web, correu, transferència de fitxers | Streaming, jocs online, VoIP |

**Capçalera TCP** (principals camps):
- Port origen / Port destí
- Número de seqüència (ordre dels segments)
- Número d'ACK (confirmació de recepció)
- Flags (SYN, ACK, FIN...)
- Checksum

**Capçalera UDP** (molt més senzilla):
- Port origen / Port destí
- Longitud
- Checksum

> Idea clau: TCP "comprova que tot arribi bé" (com un correu certificat), UDP "envia i ja està" (com llençar un paper amb un missatge, més ràpid però sense garanties).

## 4. Encapsulament de dades

Cada capa afegeix la seva pròpia informació (capçalera) a les dades de la capa superior, com nines russes:

```
Dades → Segment (TCP/UDP) → Paquet (IP) → Trama (MAC) → Bits
```

**Segmentació dels missatges:** els missatges grans es divideixen en trossos més petits (segments/paquets) abans d'enviar-se, i es reconstrueixen a l'arribada. Permet compartir el medi entre molts usuaris i recuperar-se millor d'errors.

## 5. Abast geogràfic de les xarxes

| Tipus | Nom | Abast |
|---|---|---|
| **LAN** | Local Area Network | Un edifici o oficina |
| **MAN** | Metropolitan Area Network | Una ciutat |
| **WAN** | Wide Area Network | Un país o el món (ex: Internet) |

**FDDI** (Fiber Distributed Data Interface): tecnologia de xarxa en anell doble amb fibra òptica, usada històricament per MAN/backbones d'alta velocitat.

**Estàndard IEEE 802.***: família de normes per xarxes. Per exemple:
- 802.3 → Ethernet
- 802.11 → Wi-Fi
- (802.8 fa referència a un grup de treball sobre fibra òptica, poc usat en la pràctica actual)

## 6. Topologia de xarxa

### Física (com estan connectats físicament els cables)
- **Bus**: tots connectats a un mateix cable central.
- **Estrella**: tots connectats a un dispositiu central (switch/hub).
- **Anell**: cada dispositiu connectat als dos veïns, formant un cercle.
- **Malla**: cada dispositiu connectat amb diversos altres (redundància).

### Lògica
Com **flueixen realment les dades**, independentment del cablejat físic (ex: una xarxa amb topologia física en estrella pot funcionar lògicament com un bus).

## 7. Tipus d'accés

Mètodes per decidir com els dispositius comparteixen el medi:
- **CSMA/CD** (Ethernet clàssic): escolta abans de transmetre, detecta col·lisions.
- **CSMA/CA** (Wi-Fi): evita col·lisions abans que passin.
- **Token Passing**: es passa un "testimoni" que dona permís per transmetre.

## 8. Medis de transmissió

| Guiats (amb cable) | No guiats (sense cable) |
|---|---|
| Parell trenat (UTP/STP) | Ones de ràdio (Wi-Fi) |
| Cable coaxial | Infraroigs |
| Fibra òptica | Microones (satèl·lit) |

## 9. Dispositius d'interconnexió

| Dispositiu | Capa OSI | Funció |
|---|---|---|
| **Hub** | 1 (Física) | Repeteix el senyal a tots els ports, sense intel·ligència |
| **Switch** | 2 (Enllaç) | Envia les trames només al port correcte (segons MAC) |
| **Bridge** | 2 (Enllaç) | Uneix dos segments de xarxa, filtrant per MAC |
| **Router** | 3 (Xarxa) | Interconnecta xarxes diferents, encamina per IP |
| **Firewall** | Diverses | Filtra trànsit per seguretat (regles) |
| **Modem** | 1 (Física) | Converteix senyal digital ↔ analògic (per exemple, línia telefònica/fibra) |
| **Punt d'accés inalàmbric (AP)** | 1-2 | Permet connexió Wi-Fi a la xarxa cablejada |

> Idea per recordar: **Hub = "burro"** (no pensa, reenvia a tothom) → **Switch = "intel·ligent"** (sap on enviar cada cosa) → **Router = "frontera"** (connecta xarxes diferents).

## 10. Tipus de xarxa segons accés

| Tipus | Descripció |
|---|---|
| **Xarxa pública** | Accessible per qualsevol (ex: Internet) |
| **Xarxa privada** | Accés restringit (ex: xarxa interna d'una empresa) |
| **Xarxa privada virtual (VPN)** | Connexió xifrada que simula una xarxa privada a través d'una xarxa pública |

---

**Idea clau general:** tot el funcionament d'una xarxa es pot entendre com capes que treballen juntes (model OSI): cada dispositiu i protocol té un "pis" concret on actua, i les dades es van "embolicant" (encapsulant) a mesura que baixen fins arribar al medi físic.
