# Apunts: Fonaments de Maquinari — Instruccions Bàsiques i Multiplexor (1r ASIX)

## 1. La màquina senzilla

**"Màquina senzilla":** model simplificat d'un processador/computador que es fa servir per entendre com funciona una CPU real per dins, sense tota la complexitat d'un processador comercial modern.

**Elements típics d'una màquina senzilla:**
- Un conjunt reduït d'**instruccions** bàsiques (moure dades, sumar, comparar, saltar...).
- Uns quants **registres** (petites memòries dins la CPU).
- Una **memòria** on es guarden dades i el programa.
- Un **comptador de programa (PC)** que indica quina instrucció toca executar.

> Idea clau: entendre una màquina senzilla permet comprendre el **cicle bàsic** de qualsevol CPU (buscar instrucció → decodificar-la → executar-la), sense necessitat d'aprendre'n una de real i complexa de bon principi.

## 2. Instruccions bàsiques

Aquestes instruccions són representatives del tipus de llenguatge assemblador que fa servir una CPU (el nom exacte pot variar segons l'arquitectura, però el concepte és el mateix arreu):

### MOV — Moure dades

Copia un valor d'un lloc a un altre (registre ↔ registre, memòria ↔ registre, o un valor constant a un registre).

```asm
MOV R1, R2      ; copia el valor de R2 a R1
MOV R1, 5       ; posa el valor 5 a R1
```

> No "mou" en el sentit literal (no esborra l'origen), sinó que **copia**.

### ADD — Suma

Suma dos valors i guarda el resultat.

```asm
ADD R1, R2, R3   ; R1 = R2 + R3
```

### CMP — Comparar

Compara dos valors (normalment fent una resta internament) i actualitza uns **flags** (indicadors) segons el resultat (zero, negatiu, etc.), **sense guardar** el resultat de la resta enlloc.

```asm
CMP R1, R2      ; compara R1 amb R2 → actualitza flags
```

> Idea clau: CMP no serveix per res "sol" — el seu resultat (els flags) s'utilitza just després per una instrucció de salt condicional, com BEQ.

### BEQ — Branch if Equal (Salt condicional si són iguals)

Salta a una altra part del programa **només si** la comparació anterior (CMP) ha donat "iguals".

```asm
CMP R1, R2
BEQ etiqueta     ; si R1 == R2, salta a "etiqueta"
```

**Exemple d'ús conjunt (com un `if`):**
```asm
CMP R1, R2
BEQ son_iguals    ; si són iguals, salta
; ... codi si NO són iguals ...
son_iguals:
; ... codi si SÍ són iguals ...
```

> Idea per recordar: **CMP "pregunta"**, **BEQ "decideix on saltar" segons la resposta**. Junts, són la base de com un ordinador fa condicionals (`if`) i bucles (`while`, `for`) a baix nivell.

## 3. Multiplexor (MUX)

**Multiplexor (MUX):** circuit combinacional que **selecciona una entrada d'entre diverses**, i la passa a la sortida, segons el valor d'unes línies de **selecció**.

**Funcionament bàsic (MUX 2 a 1):**

| Entrades de dades | Selecció (S) | Sortida |
|---|---|---|
| A, B | 0 | Sortida = A |
| A, B | 1 | Sortida = B |

```
A ──┐
    │  MUX
B ──┤────── Sortida
    │
S ──┘  (línia de selecció)
```

**MUX de més entrades:** per triar entre **N entrades**, calen **log₂(N) línies de selecció**.
- MUX 2 a 1 → 1 línia de selecció
- MUX 4 a 1 → 2 línies de selecció
- MUX 8 a 1 → 3 línies de selecció

> Analogia: un multiplexor és com un **canviador de canals de TV** — tens diverses "entrades" (canals) però només un "cable de sortida" cap a la pantalla, i tu decideixes quin canal es veu prement el número (selecció).

**Per què és important dins la CPU:**
El multiplexor és una peça clau per construir circuits més complexos: per exemple, per decidir **quina dada envia l'ALU** a un registre, o **quina instrucció s'executa** segons el resultat d'una comparació (relacionat directament amb com funciona un `BEQ` per dins!).

---

**Idea clau general:** instruccions com `MOV`, `ADD`, `CMP` i `BEQ` són els "blocs de construcció" bàsics amb què es programa qualsevol lògica a baix nivell (moure dades, calcular, decidir i saltar); i per dins del maquinari, circuits com el **multiplexor** són els que fan físicament possible "triar" quin camí segueix la informació — per exemple, triar quina instrucció s'executa després d'una comparació.
