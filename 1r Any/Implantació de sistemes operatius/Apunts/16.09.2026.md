# Conceptes bàsics de Sistemes Informàtics (1r ASIX)

## 1. Arquitectura de Von Neumann

Model que defineix com funciona un ordinador. Es basa en el fet que *dades i instruccions comparteixen la mateixa memòria*.

*Elements principals:*

- *CPU** (processador): executa instruccions. Té ALU (operacions) + Unitat de Control (coordina).
- *Memòria**: guarda dades i programes (RAM).
- *Busos**: canals que connecten tot (dades, direccions, control).
- *E/S**: perifèrics (teclat, pantalla, disc...).

> Idea clau: com tot passa pel mateix bus, hi ha un "coll d'ampolla" (coll d'ampolla de Von Neumann).

## 2. Maquinari vs Programari

||Maquinari|Programari|
|---|---|---|
|Què |és|Part física, tangible|Programes, instruccions|
|Exemples|CPU, RAM, disc, teclat|SOTA, aplicacions, drivers|
|Es pot tocar|Sí|No|

*Sistema informàtic* = Maquinari + Programari + (usuàries/dades) treballant junts per a processar informació.

## 3. La informació en l'ordenador

- *Bit**: unitat mínima d'informació. Només pot valer *0 o 1*.
- *Byte**: conjunt de *8 bits*. És la unitat bàsica per a mesurar memòria/emmagatzematge.
- *Binari**: sistema numèric que usa només aquests dos símbols (0 i 1) — és l'"idioma" que entén el maquinari.

## 4. Sistemes de numeració (bases)

Un sistema de numeració en base *N** usa N símbols distints (del 0 al N-1).

|Sistema|Base|Símbols usats|
|---|---|---|
|Decimal|10|0-9|
|Binari|2|0-1|
|Octal|8|0-7|
|Hexadecimal|16|0-9 i A-F (A=10, B=11... F=15)|

> L'hexadecimal s'usa molt perquè és *compacte**: 1 dígit hex = 4 bits exactes, així que és fàcil de convertir a binari i ocupa menys espai en escriure (útil per a adreces de memòria, colors, MAC, etc.).

## 5. Conversions — mètode ràpid

*Binari → Decimal*
Multiplica cada bit per 2^posició (de dreta a esquerra, començant en 0) i suma.

```
1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8+0+2+1 = 11₁₀
```

*Decimal → Binari*
Divisions successives entre 2, agafant les restes de baix cap amunt.

```
11 ÷ 2 = 5 resta 1
5 ÷ 2 = 2 resta 1
2 ÷ 2 = 1 resta 0
1 ÷ 2 = 0 resta 1
→ 1011₂
```

*Hexadecimal → Binari*
Cada dígit hex es converteix a *4 bits* directament (taula mental de 0000 a 1111).

```
A3₁₆ → A=1010 3=0011
→ 10100011₂
```

---

*Idea per a recordar:* tot es redueix a bits (0/1) perquè és l'única cosa que el maquinari distingeix físicament (hi ha corrent o no n'hi ha); decimal, octal i hex són només formes més còmodes per als humans de representar aquests mateixos bits.
