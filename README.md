# 📚 Apunts ASIX

Repositori amb els meus apunts diaris durant els estudis del cicle **ASIX (Administració de Sistemes Informàtics en Xarxa)**.

> ⚠️ **Nota:** Tots els apunts estan escrits en **català**. / Todos los apuntes están escritos en **catalán.**

> 🤖 Ús d'IA: Alguns apunts es generen o s'organitzen amb l'ajuda d'IA, com a suport per millorar el rendiment acadèmic i optimitzar el temps dedicat a redactar-los. El contingut es revisa i s'adapta al meu propi aprenentatge.

## 📂 Estructura

Els apunts estan organitzats per mòdul/assignatura:

```
📁 ASIX/
├── 📁 1r Any
  ├── 📁 Fonaments de maquinari/Apunts/
  ├── 📁 Implantació de sistemes operatius/Apunts/
  ├── 📁 Llenguatge de marques i sistemes de gestió d'informació/Apunts/
  ├── 📁 Gestió de bases de dades/Apunts/
  ├── 📁 Planificació i Administració de xarxes/Apunts/
  ├── 📁 Anglès/Apunts/
├── 📁 2n Any
  └── ...
```

Cada carpeta conté els apunts organitzats per tema o data, normalment en format Markdown.

## 🎯 Objectiu

Aquest repositori té dues finalitats:
- Portar un registre organitzat i accessible del que vaig aprenent.
- Tenir un recurs de repàs ràpid abans d'exàmens.
